# Final submission checklist

- [x] Author name, student ID, email, supervisor, school, and course lab are included.
- [x] Abstract is 200-300 words and contains motivation, methodology, quantitative results, and significance.
- [x] Keywords contain five course/task terms.
- [x] Introduction states the problem, course connection, research question, three contributions, and organization.
- [x] Related work explains structural, visual, and language-intelligence foundations and the research difference.
- [x] Methodology includes definitions, equations, an architecture diagram, and an experimental flowchart.
- [x] Experiments use a public dataset, fixed split, reproducible settings, baselines, metrics, and hardware details.
- [x] Results include the main table, controlled ablation, convergence curves, and qualitative predictions.
- [x] Discussion includes interpretation, advantages, limitations, course learning reflection, future work, and threats to validity.
- [x] Conclusion is approximately 200 words and introduces no new result.
- [x] IEEE-style numbered references are used.
- [x] Source code link is public: https://github.com/hammiroussama/lightweight-transformer-unet-kvasir
- [x] A4 paper, 2.5 cm margins, Times-family text, 1.5 spacing, and centered page numbers are configured.
